## 二、三个硬件级限制（改不掉的）

### 1. WiFi + 蓝牙

**芯片**：Realtek RTL8822BE（M.2 2230）

**问题**：macOS 下**零驱动**。不是配置问题，是芯片本身不被支持。

**唯一解**：换成 **博通 BCM94360NG**（M.2 2230，几十块）。

换完可获得：WiFi、蓝牙、隔空投送（AirDrop）、接力（Handoff）、通用剪贴板、随航。

### 2. HDMI 输出

**问题**：HDMI 口物理连接在 GTX 1050 Ti（Optimus 独显）上，而 Pascal 无 macOS 驱动。

**影响**：外接显示器走 HDMI 永远不出图。

**可能的替代**：USB-C / DP 口如果走核显（需确认），可能可以。

### 3. 独显 GTX 1050 Ti

**处理**：`SSDT-DDGPU` 已在 ACPI 中屏蔽（省电、避免冲突）。

**影响**：无 GPU 加速的视频剪辑 / 3D / 游戏 / 本地 AI 训练。

## 三、性能相关的两个发现

### 1. 内存 8GB + 16GB 混插

~~~
BANK 0: Samsung 8GB  (M471A1K43CB1-CTD)
BANK 2: Kingston 16GB (KHX2666C15S4/16G)
~~~

Intel Flex Mode：只有 8+8 走双通道，剩余 8GB 单通道。

**影响**：核显共享内存带宽下降 → UI 动画可能轻微掉帧。

**建议**：换 16+16 对称内存（顺带解决大型项目内存压力）。

### 2. 电池健康度

~~~
Full Charge Capacity: 2723 mAh
Cycle Count:          416
Condition:            Service Recommended
~~~

**建议**：换电池（约 200–300 元）。这是硬件老化，不是黑苹果问题。

## 四、验证命令合集

~~~bash
# 硬件总览
system_profiler SPHardwareDataType
system_profiler SPDisplaysDataType | grep -E 'Chipset|Metal|Resolution'
system_profiler SPAudioDataType | grep -E 'Devices|Output|Input'
# kext 加载情况
kextstat | grep -Ei 'lilu|virtualsmc|whatevergreen|applealc|voodoo|realtek'
# 网络
ifconfig en0 | grep -E 'status|media|inet '
# 电池
pmset -g batt; system_profiler SPPowerDataType | grep -E 'Cycle|Condition'
# 睡眠
pmset -g; pmset -g log | grep -E 'Sleep|Wake' | tail
# 摄像头
system_profiler SPCameraDataType
~~~
