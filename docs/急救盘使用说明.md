# macOS 急救盘使用说明（2026-11-08）

## 这只 U 盘的结构

| 分区 | 内容 | 作用 |
|---|---|---|
| 1 | macOS Sequoia 15.6.1 恢复系统（HFS+，2.7 GB） | 装系统 / Time Machine 恢复 / 磁盘工具 |
| 2 | OpenCore 0.8.8 引导（EFI，1 GB） | 引导器，必须先经过它 |
| 3 | RESCUE 数据区（exFAT，25.6 GB） | EFI 备份、文档、临时文件 |

---

## 场景 A：系统进不去 / 想恢复

1. 插 U 盘 → 开机 **F12** → 选 `UEFI: TOSHIBA TransMemory-Ex`
2. OpenCore 菜单（文字）→ 选 `macOS Base System`
3. 进入恢复界面后：
   - **恢复数据**：选「从时间机器恢复」→ 选内置 1TB 盘上的 `TimeMachine` 卷
   - **重装系统**：选「重新安装 macOS」（需联网，会从 Apple 下载约 12 GB）
   - **修磁盘**：选「磁盘工具」→ 急救（First Aid）

## 场景 B：EFI 丢失或损坏（黑屏/进不了 OpenCore）

1. 用这只 U 盘启动（它的 EFI 是好的）→ 进 macOS
2. 打开终端，解压备份：

~~~bash
sudo diskutil mount disk0s1
sudo rm -rf /Volumes/EFI/EFI
sudo unzip -q /Volumes/RESCUE/EFI-backup-2026-11-08.zip -d /Volumes/EFI/
~~~

3. 重启

## 场景 C：在恢复环境里直接写 EFI

恢复环境里打开「终端」：

~~~bash
diskutil list                    # 找到内置硬盘的 EFI 分区
diskutil mount disk0s1
cd /Volumes
ls                               # 找到 RESCUE
cd /Volumes/RESCUE
unzip -q EFI-backup-2026-11-08.zip -d /Volumes/EFI/
~~~

---

## 重要提醒

- **Time Machine 不备份 EFI**，恢复数据后如果系统起不来，按场景 B 写回 EFI
- 恢复系统本身**不含 macOS 本体**，重装需要联网下载约 12 GB
- 不要格式化这只 U 盘的分区 1 和 2
- 内置 1TB 盘上的 `TimeMachine` 卷是日常备份，别删
