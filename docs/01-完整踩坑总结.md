## 四、重点坑详解

### 坑 5：EXITBS:START 卡死（最贵的一个，3.5 小时）

**现象**

~~~
OC: 进入引导 → 黑屏 → 停在 EB|LOG:EXITBS:START → 无限等待
~~~

**排除过程**（这是最有价值的部分：用对照实验排除）

| 变量 | 实验 | 结论 |
|---|---|---|
| 配置语法 | `ocvalidate` 全绿 | 不是配置错 |
| OC 版本 | 0.8.8 / 1.0.7 / 1.0.8 全试 | 全都卡 → 不是版本 |
| 安装介质 | Ventura / Sequoia 都试 | 全都卡 → 不是介质 |
| kext | 精简到只剩 Lilu | 仍卡 → 不是 kext |
| **BIOS** | 唯一没动的变量 | **就是它** |

**根因**

这台 InsydeH2O 固件的 4 个隐藏项没配好，macOS 内核在交接启动服务时失败：

| 变量 | 位置 | 原值 | 正确值 | 作用 |
|---|---|---|---|---|
| CFG Lock | `CpuSetup 0x3E` | 01 | **00** | 关闭 MSR 0xE2 写保护 |
| DVMT Pre-Allocated | `SaSetup 0x107` | 01 | **02** | 核显显存 32MB → **64MB** |
| Kernel Debug | `PchSetup 0x08` | 03 | **00** | 关闭 8 代平台的调试锁 |
| GPIO 中断 | `PchSetup 0x18` | 00 | **01** | 开启触控板中断 |

**解决**

1. 下载 `xiaoMGitHub/LEGION_Y7000Series_Insyde_Advanced_Settings_Tools`
2. Windows 下运行 `双击执行.bat`（会自动备份原始变量到 `Backup\`）
3. 改完**重新读取验证**（工具里有 Verify 选项）
4. 重启进 OC → 一次通过

**证据**：改完后同一个 EFI、同一个安装介质，EXITBS 直接通过。

### 坑 10/11：菜单黑屏（图形资源 + 渲染器）

**现象 A**：OC 加载后黑屏，无菜单

~~~
OCUI: Failed to load images for Acidanthera\GoldenGate
~~~

根因：仓库 EFI 缺 `Resources` 目录（OpenCanopy 主题图标）。
解决：从教程 EFI 复制 `Resources`（22 个 GoldenGate 图标）。

**现象 B**：补了资源仍黑屏（Builtin 纯文本模式也黑）

根因：这台固件的 GOP 在文本模式下不刷新。
解决：`UEFI → Output → DirectGopRendering = true`（直接写帧缓冲）。

**最终可用组合**：

~~~
PickerMode        = Builtin
DirectGopRendering = true
TextRenderer      = BuiltinGraphics
ProvideConsoleGop = true
Timeout           = 5
~~~

### 坑 13：OpenCore 版本与配置 schema 不匹配

**现象**：`ocvalidate` 报 `HideVerbose` / `VaultPlugin` 不存在于 0.8.8 schema

**根因**：配置来自 1.0.8 时代的仓库，字段在 0.8.8 里没有。

**解决**：不要混用。两种走法：

| 走法 | 做法 |
|---|---|
| A（推荐） | 用 0.8.8 的 `config_8300H_8750H.plist` 为底，把 kext/ACPI 换成新的 |
| B | 用 1.0.8 全套（但本机过不了 EXITBS） |

**本机选了 A**：0.8.8 引导器 + Sequoia 时代的 kext（Lilu 1.7.2 / VirtualSMC 1.3.7 / WEG 1.7.0）。

### 坑 19：Time Machine 备份到 U 盘失败

**现象**：写到 22GB 后停在最后一步，目录名一直是 `.previous` / `.inprogress`，`tmutil listbackups` 不认。

**根因**

1. 系统完整备份需要 **28.9 GB 逻辑 / 22 GB 物理**
2. U 盘的 APFS 卷只有 **26 GB**
3. 封存阶段还需要额外空间 → 剩下 3.3 GB 不够 → 失败
4. 中途 `tmutil removedestination` 会让已完成的数据变成孤儿（还占着空间）

**正确做法**

- 整机镜像至少需要 **64 GB** U 盘
- 26 GB 的 U 盘只做「急救盘」（恢复系统 + EFI 备份）
- 日常整机备份放内置 1TB 盘

**清理孤儿备份的命令**

~~~bash
tmutil stopbackup
rm -rf /Volumes/TM/*.previous /Volumes/TM/*.inprogress
diskutil apfs listSnapshots disk11s2          # 找残留快照
diskutil apfs deleteSnapshot disk11s2 -uuid <UUID>
~~~

### 坑 21：改分辨率后黑屏

**现象**：系统设置里把分辨率调成缩放档（1280×720 之类）→ 立刻黑屏，但系统还在跑（SSH 能连）。

**根因**：UHD 630 的帧缓冲不支持该缩放模式，WindowServer 拿不到可用时序。

**解决（远程即可）**

~~~bash
# 1. 备份并删除显示配置
mkdir -p ~/Desktop/display-backup
sudo cp /Library/Preferences/com.apple.windowserver* ~/Desktop/display-backup/
sudo rm -f /Library/Preferences/com.apple.windowserver.plist
sudo rm -f /Library/Preferences/com.apple.windowserver.displays.plist
sudo rm -f ~/Library/Preferences/ByHost/com.apple.windowserver.*.plist
# 2. 重启
sudo shutdown -r now
~~~

**预防**：只选 macOS 明确列出的档位，别选带「更多空间/更大文字」的自定义缩放，除非确认显示器支持。

## 六、方法论：下次再装应该怎么做

### 顺序不要变

~~~
1. BIOS 隐藏项（CFG Lock / DVMT / KernelDebug / GPIO）  ← 不做必卡
2. 用「已验证能启动」的 EFI 版本（本机 = 0.8.8）
3. 先修菜单显示（DirectGopRendering），再谈安装
4. 安装（联网，12GB 下载）
5. 补 kext / ACPI / 三码
6. EFI 落盘 + Time Machine + 急救盘
~~~

### 排障的四条铁律

1. **一次只改一个变量**——EXITBS 那次就是靠这个定位的
2. **拿日志说话**——`opencore-*.txt` 的尾部决定下一步
3. **保留一个已知能启动的 EFI**（U 盘），永远别把唯一的引导源覆盖掉
4. **别相信「看起来成功了」**——计划任务、TM 备份都出现过假成功，要验证产物

### 常见误区

| 误区 | 现实 |
|---|---|
| 「OC 版本越新越好」 | 本机 1.0.x 全部卡 EXITBS，0.8.8 才行 |
| 「配置抄一份就能用」 | 同型号不同 BIOS 版本都可能不同 |
| 「装完就完事」 | EFI 不落盘 = 拔 U 盘就进不去 |
| 「iCloud 登不上是配置问题」 | 也可能是账号被风控（本次就是） |
