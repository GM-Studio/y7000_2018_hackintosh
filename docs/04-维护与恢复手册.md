# 04 · 维护与恢复手册

## 一、日常维护（每月 10 分钟）

| 项目 | 怎么做 | 目的 |
|---|---|---|
| Time Machine | 系统设置 → 通用 → Time Machine，确认最近备份日期 | 系统崩了能还原 |
| EFI 备份 | 改过配置后重新打包一份 | 引导崩了能救 |
| 系统更新 | **只装安全更新，绝不升大版本** | 避免引导失效 |
| 电池健康 | `system_profiler SPPowerDataType` | 及早发现鼓包 |

## 二、三条铁律

1. **不要升级 macOS 大版本**（15 → 26 之类），黑苹果大概率直接起不来
2. **不要开 FileVault**（加密后 OpenCore 引导会失败）
3. **永远保留一个能启动的 U 盘**

## 三、故障恢复场景

### 场景 A：系统能启动，但设置乱了 / 想回滚

~~~
系统设置 → 通用 → Time Machine → 浏览备份 → 恢复
~~~

### 场景 B：系统启动不了，但能进 OpenCore

1. OpenCore 菜单选 `macOS Base System`（U 盘或内置恢复分区）
2. 选「从时间机器恢复」→ 选 `TimeMachine` 卷
3. 恢复完成后重启

### 场景 C：连 OpenCore 都进不去（黑屏）

**原因通常**：EFI 分区被破坏 / 配置改错。

~~~bash
# 用 U 盘启动进系统，然后：
sudo diskutil mount disk0s1
sudo rm -rf /Volumes/EFI/EFI
sudo cp -R /Volumes/<U盘>/EFI /Volumes/EFI/
sudo diskutil unmount disk0s1
~~~

### 场景 D：整块硬盘重装

1. U 盘启动 → 磁盘工具 → 抹掉系统盘（APFS / GUID 分区图）
2. 重新安装 macOS（联网下载 12GB）
3. 装完进系统 → 挂载 ESP → 复制本归档的 EFI
4. 重启验证（拔 U 盘能启动才算成功）

## 四、急救 U 盘结构（当前这只）

~~~
U 盘 31.8 GB
├─ 分区1 HFS+  「macOS Base System」3.1 GB  ← 恢复环境
├─ 分区2 FAT32 EFI                   1.1 GB  ← OpenCore 0.8.8
└─ 分区3 APFS  「RESCUE」            27.5 GB
    ├─ EFI-backup-2026-11-08.zip            ← 可启动 EFI 备份
    ├─ README-EFI备份说明.md
    └─ 急救盘使用说明.md
~~~

**能做什么**：引导、进恢复环境、重装系统、还原 EFI。
**不能做什么**：离线还原整机（需要 64GB U 盘才装得下 Time Machine 镜像）。

## 五、常用命令速查

### 挂载 / 卸载 EFI 分区

~~~bash
sudo diskutil mount disk0s1
ls /Volumes/EFI
sudo diskutil unmount disk0s1
~~~

### 备份 EFI

~~~bash
sudo diskutil mount disk0s1
cd /Volumes/EFI
sudo zip -r ~/Desktop/EFI-backup-$(date +%F).zip EFI
~~~

### 重建 Time Machine 目标

~~~bash
sudo tmutil setdestination -a /Volumes/TimeMachine
sudo tmutil enable
sudo tmutil startbackup --auto
tmutil status
~~~

### 修复「改分辨率后黑屏」

~~~bash
sudo rm -f /Library/Preferences/com.apple.windowserver*.plist
sudo rm -f ~/Library/Preferences/ByHost/com.apple.windowserver.*.plist
sudo reboot
~~~

### 检查 kext 是否加载

~~~bash
kextstat | grep -Ei 'lilu|virtualsmc|whatevergreen|applealc|voodoo|realtek|nvmefix'
~~~

### 查看启动日志（需先开日志）

~~~bash
# 在 config.plist 里把 Misc->Debug->Target 改成 67，重启后：
ls -t / | grep opencore
~~~

## 六、升级策略

| 类型 | 建议 |
|---|---|
| 安全更新（15.8.2 → 15.8.3） | 可以装，但**先备份 EFI** |
| 小版本（15.x → 15.y） | 谨慎，装前备份 EFI + Time Machine |
| **大版本（15 → 26）** | **不要装**，必挂 |

## 七、换硬件时要注意

| 换什么 | 影响 |
|---|---|
| WiFi 卡换 BCM94360NG | 正收益，WiFi/蓝牙/AirDrop 全通 |
| 加内存（16+16） | 正收益，核显带宽提升 |
| 换电池 | 正收益 |
| 换硬盘 | 需要重新装系统 + 写 EFI |
| **刷 BIOS** | **必须重做 4 个隐藏变量** |
